# JSON C# Project

## Aprasymas
Sis projektas parodo kaip:
- sukurti JSON faila rankiniu budu
- prideti kelis vartotojus
- deserialize JSON duomenis i C# objektus
- naudoti loop visu irasu isvedimui
- naudoti inheritance (`AdminUser`, `RegularUser`)
- sukurti antra JSON faila su user types

## Galutine Versija
Projektas Sukuria Vartotojus ir sukelia i JSON faila:
- Pirma yra visos klases ir paveldetos klases
- Tuomet pirmoje dalyje sukuriami 3 nauji vartotojai
- jie yra surasomi i JSON faila ir parodomi konsoleje
- Antroje dalyje sukuriami kito tipo vartotojai
- jie yra surasomi i kita JSON faila ir parodomi konsoleje
